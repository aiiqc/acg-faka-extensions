# 店铺共享准入

本说明对应 `PikaSharedAccess 0.1.0`。该扩展复用现有管理器的启停、配置表单和站外存储，不修改官方核心、现有桥、货源同步或主题。源码和隔离验证不代表任意站点已部署；实际启用及验证由目标站点单独执行。

## 设置与效果

安装后默认关闭，保持原生共享行为。在后台“本地扩展”的“店铺共享准入”卡片中，先保存允许名单，再启动扩展。只匹配已通过原生签名验证的本站商户账号与其对应服务器来源，不使用请求正文声称的账号代替认证结果。

名单使用英文逗号分隔的 `账号ID@IP`，最多 100 对、4096 字节。示意：`101@192.0.2.10,102@2001:db8::10`（仅为文档保留地址，不可照填）。账号必须是正整数；同账号有多个真实出口时分别增加配对。IPv4、IPv6 按地址值精确比较，IPv4-mapped IPv6 与对应 IPv4 视为同址。不支持域名、端口、CIDR、通配符或重复配对；不会把账号列表与地址列表交叉放行。

来源只取 Web 服务器已规范化的 `REMOTE_ADDR`，本扩展不重新信任 `X-Forwarded-For` 等请求头。代理或 CDN 必须由站点管理员在可信网络层正确恢复真实来源；不能把共享代理地址误当某个分站的独占来源。保留既有 HTTPS 地址、证书验证及 SSRF 防护，不把货源改成私网／回环地址。

启动后，空名单或缺失配置会拒绝全部原生共享接入；规则无效、文件损坏、权限异常、缺少认证用户或配对不符也拒绝。拒绝沿原生 JSON 业务响应返回 `code: 403` 和固定消息“共享接口未获准访问”，不会输出账号、IP、规则或密钥。HTTP 状态沿用原生业务响应惯例，不据 HTTP 200 判断准入成功。

关闭扩展恢复原生共享行为，不删除名单，不改账号或商品权限，也不触发同步。保存相同名单不触发外部请求、业务写入或同步；仅沿既有 ConfigStore 原子保存配置。后台设置写入仍受原 Owner 会话、POST 和会话绑定 CSRF 门约束。

## 精确作用范围

仅在真实控制器调用前检查 `App\Controller\Shared\Authentication` 和 `App\Controller\Shared\Commodity` 的所有 action，包括 connect、目录、商品详情、库存、交易、卡密、订单查询和估价。以 Kernel 已解析的类为准，等价路由写法不会因 URL 字符串不同而绕过。原生签名仍在此前验证。

不拦截 `Shared\Plugin::face`、`User` 接口、普通页面、后台登录或支付回调；这不是关闭注册、商品网页购买或限制全站访问。已启用扩展的其他原生权限也不会被本准入放宽。

检查复用 `Runtime::hook(0x31)` 中 Dispatcher 返回后的强制位置，不注册可被 bool／Stock 短路的 manifest 回调。拒绝抛出原生 `JSONException`，Kernel 不再调用控制器 action；返回 false 不能替代此门。Dispatcher 或原生回调本身抛错也终止该次 action，不吞异常。受信原生回调先于此位置执行，因此本门不声称阻止其他受信插件在自身回调中执行的行为。

## 存储、恢复与验收

不在源码写真实账号或 IP。沿用站外路径：`/var/lib/pika-local-extensions/sites/<SHA256(realpath(site-root))>/runtime/config/PikaSharedAccess.json`，内容为 `{"schema":1,"values":{"allowed_clients":"..."}}`。启停条目位于相同 runtime 下的 `state.json`。配置文件由原 `AtomicJson` 以运行用户归属、`0600` 权限保存，目录使用原 `PathGuard` 约束；不新增数据库、服务、定时器或独立状态系统。

仅准入配置损坏时，其卡片显示固定错误而非假空表单，并保留“停止”入口，不连带隐藏其他扩展。管理员可先停用，再在准确站外路径按原权限修复；本扩展不自动覆盖损坏文件，不降低整个管理器的完整性检查。整体注册表或管理器公共状态损坏仍属于现有安装／恢复边界。

部署须保留最新站外配置、业务状态与安装回执，不把旧快照覆盖到当前 Supply 游标／schedule。制品须以实际内容 SHA、精确文件清单及对应提交识别；新源码提交不改写既有站点部署回执，二者只能通过内容核对建立对应关系。回退代码不自动恢复准入规则或其他业务数据。

隔离验收使用合成账号、签名、来源及 SQLite；分别核对默认关闭、允许配对、交叉配对拒绝、损坏配置、短路与异常、真实 Kernel 路由以及 action／副作用未执行。生产验收应使用最小只读 connect；真实交易、卡密获取和订单写入不在本批验证范围。
