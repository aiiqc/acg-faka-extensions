# 订单支付结果等待（PikaOrderReturnWait）

这是 Acg-Faka Extensions 中的 Pika 插件，不使用异次元应用商店的插件状态、生命周期或静态资源目录。
启用状态由 LocalExtensions 管理器维护；`bootstrap.php` 只注册本包命名空间的自动加载。

插件只在远程支付返回后的订单结果页工作：当原页面确认订单仍待付款时，显示短暂等待提示，并通过整页刷新复用异次元原有的订单查询与权限校验。

- 不修改支付回调。
- 不在 PHP 中等待或休眠。
- 不新增订单查询 API。
- 余额支付和零元订单不会触发等待。
- 到达最长等待时间后停止刷新，保留原订单查询页面和联系客服入口。

设置由 LocalExtensions 管理器按照 `local-extension.json` 的白名单结构保存：

- `最长等待秒数`：5–120 秒，默认 15 秒。
- `页面刷新间隔`：1–10 秒，默认 2 秒。插件会根据最长等待时间自动提高实际间隔，单次等待最多自动刷新 15 次，避免触发官方查询限流。
- 浏览器禁用会话存储时，插件会停止自动刷新并保留手动查询入口，不会反复重载页面。

前端资源由安装器从包内 `Assets/` 精确复制到
`/assets/local-extensions/PikaOrderReturnWait/`；Web 进程不会复制或发布扩展源码目录。
