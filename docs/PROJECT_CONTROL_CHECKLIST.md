# 公开候选审核与发布清单

当前状态以 [PROJECT_STATUS.md](PROJECT_STATUS.md) 为准。本清单面向维护者，不保存私人站点运行流水，也不授权部署、交易或仓库公开操作。

## 候选审核

- 从已核实的固定文件集合准备快照，不携带 `.git`、未跟踪文件、运行日志、数据库、缓存或凭据。
- 代码、主题与媒体变动须有明确范围；只整理文档或示例时核对业务载荷与来源的 hash/模式一致性。
- 新安装推荐固定官方 3.7.9；旧版只保留实际兼容与验证边界，不改变指纹绕过安装保护。
- 公开文本、测试样例及图片/视频分别检查；零秘密规则命中不是无秘密保证，视频抽帧不等于逐帧审查。
- 代码 MIT、上游版权和第三方媒体边界分别说明；出处、免费分发或侵权移除声明不能替代再分发许可。
- 保留配置、恢复及失败边界说明，不因脱敏删除用户需要的安全操作步骤。
- 运行本批受影响的现有测试，核对相对链接及待发布占位；没有变更或失败时不重复整套部署矩阵。

## 实际公开前

- 确认准确仓库名称、可见性、发布内容及用户批准；本地候选不能自动触发公开。
- 核定最终清单、hash 与制品身份；填入真实公开获取入口，完成匿名下载/校验后才称可下载。
- 按 [CONTRIBUTING.md](../CONTRIBUTING.md) 提供贡献范围、依赖条件和真实测试入口。
- 按 [SECURITY.md](../SECURITY.md) 配置并验证私密漏洞报告方式；“推荐启用”不等于渠道已可用。
- 明确第三方素材许可未确认项，以及本发行版的实际承诺和未覆盖验证范围。
- 约定的用户完整流程、部署和真实业务证据分别收口；不能用隔离测试、截图或服务健康替代。

## 范围与停止条件

保持官方业务核心及既有扩展路径，不建立第二套同步或支付实现。发现敏感信息、来源差异、失败或许可不确定时，先准确记录并在对应层处理，不默认为可以扩大生产操作、重写私人历史或发布。原开发历史和运行证据由其现有私有流程保留，不复制进公开候选。
